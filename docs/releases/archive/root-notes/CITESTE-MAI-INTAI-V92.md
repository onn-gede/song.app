# SongApp v92 · instalator Windows pentru conectorul FreeShow

Această versiune adaugă un wizard Windows pentru instalarea conectorului local FreeShow.

## Instalare

1. Descarcă `SongApp-FreeShow-Connector-Setup-Windows.zip` din pagina **Administrare**.
2. Extrage complet arhiva.
3. Deschide `SETUP-CONNECTOR.cmd`.
4. Alege dacă dorești pornire automată cu Windows și pornire imediată.
5. Apasă **Instalează**.

În meniul Start, folderul **SongApp FreeShow** conține comenzile de pornire, oprire și dezinstalare.

Instalarea este per utilizator, în `%LOCALAPPDATA%`, și nu necesită drepturi de administrator.
