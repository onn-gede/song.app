- public/privat folosește un lacăt, iar notificările folosesc un clopot cu număr;

- editarea întâlnirii este accesibilă prin iconița de lângă dată;
- pagina programelor afișează cel mult șase înregistrări, cu paginație;
- primele trei programe active rămân carduri, iar restul sunt afișate în tabel;
- calendarul lateral permite navigarea între programările trecute și viitoare;
- programele oficiale au un accent vizual discret, iar repetițiile rămân neutre.
