# v109.2 / 0.38.2

Versiunea v109 adaugă confirmarea durabilă a versurilor corecte, export JSON al bazei de date și câmp YouTube direct în importul manual. Interfața programului separă titlul de metadate, marchează clar cântarea comună inactivă și estompează programele trecute.

Experiența mobilă ridică și mărește acțiunile fixe. Loaderul cu verset apare imediat timp de patru secunde după autentificare și după crearea unui program. La celelalte navigări, nu apare dacă pagina se încarcă în mai puțin de 1,8 secunde; când pragul este depășit, rămâne vizibil patru secunde și alternează zece versete despre slujire și închinare.
