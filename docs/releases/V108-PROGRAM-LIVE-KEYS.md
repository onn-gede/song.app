# v108 / 0.37.0

Versiunea uniformizează controalele programului, simplifică afișarea publică/live și întărește persistența tonalităților.

Tonalitatea aleasă într-un program rămâne specifică acelei apariții. Dacă piesa nu are încă tonalitate implicită, prima valoare salvată devine și tonalitatea cântării. Valorile implicite deja existente nu sunt suprascrise.

Migrarea v108 completează automat numai tonalități lipsă din colecția de tineri, pe baza unei potriviri stricte între număr și titlu. Sesiunile Supabase revocate sunt curățate controlat și utilizatorul este trimis la autentificare.
