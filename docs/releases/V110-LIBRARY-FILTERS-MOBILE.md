# v110 / 0.39.0

Biblioteca de cântări păstrează filtrele utilizatorului între accesări. La prima utilizare și după resetare, lista pornește cu colecția Cântări tineri și numerele în ordine descrescătoare.

Pe mobil există opțiunea „Fără paginare · scroll continuu”, iar rândurile sunt mai compacte. Istoricul utilizărilor nu mai ocupă permanent spațiu în listă: apare numai pentru cântările folosite, sub indicatorul roșu situat lângă tonalitate.
