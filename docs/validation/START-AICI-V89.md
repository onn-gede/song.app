# Validare SongApp v89 · proiecție și conector

## Proiecție

1. Conectează al doilea ecran.
2. Dintr-un program apasă `Prezintă` și alege al doilea ecran.
3. Confirmă că pe proiector apar doar versurile/conținutul, fără comenzile SongApp.
4. Folosește comenzile rămase pe ecranul operatorului: primul, anterior, următor, ultimul și mărimea textului.
5. Apasă `Esc` în fereastra proiecției și confirmă că aceasta se închide complet.
6. Apasă `F5`; după prima alegere trebuie reutilizat ultimul ecran.
7. Apasă `Shift + F5` și confirmă deschiderea în tabul curent.

## Conector

1. Intră în `Administrare`.
2. Descarcă `Conector FreeShow · Windows`.
3. Extrage arhiva într-un folder stabil.
4. Pornește `PORNESTE-CONNECTOR.cmd`.
5. Confirmă legătura cu FreeShow din SongApp LIVE.
6. Opțional, rulează `ACTIVEAZA-PORNIRE-AUTOMATA.cmd`.
