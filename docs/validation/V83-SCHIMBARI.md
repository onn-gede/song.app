# Schimbări v83

- tonalitatea este normalizată în interfață și prin trigger de bază de date;
- salvările de tonalitate sunt verificate în snapshotul confirmat de server;
- dialogul „Adaugă în program” permite tonalitatea și afișează numai programe în curs sau viitoare;
- prezentarea folosește text mai mare și bara de comenzi ascunsă implicit;
- importul din text permite lipire mobilă asistată și alegerea categoriei inițiale;
- fiecare cântare poate avea un link YouTube, redat într-un player încărcat numai la cerere;
- pagina publică generează metadata OpenGraph/Twitter cu titlul programului.
