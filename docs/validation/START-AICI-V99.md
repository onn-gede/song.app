# Validare V99

1. Cu conectorul pornit, indicatorul **FreeShow Sync** trebuie să fie verde.
2. Oprește conectorul; în maximum 15 secunde indicatorul trebuie să devină roșu.
3. La hover sau focus trebuie să apară explicația stării.
4. Exportă o cântare cu versuri lungi și cuvinte late; textul nu trebuie să depășească fundalul slide-ului.
5. Verifică faptul că refrenul este regular și că un slide nu conține mai mult de șase rânduri.

Nu există migrare SQL pentru această versiune.
