# Validare V100

1. Rulează `supabase/updates/UPDATE-V100.sql`.
2. Deschide **Wishlist**, adaugă o cântare și mut-o într-un program viitor; verifică programul și dispariția ei din wishlist.
3. Mută încă o cântare în backup și verifică lista corectă.
4. Exportă PPTX pentru o strofă cu 7 rânduri: slide-urile trebuie să aibă 4 și 3 rânduri.
5. Importă un link cu etichete `Strofa 1`, `[Chorus]`, `Bridge:`; etichetele nu trebuie să intre în textul versurilor.
6. Alege colecția de tineri la adăugare și verifică sugestiile YouTube. Confirmă una și verifică playerul în pagina cântării.
7. Editează o cântare existentă din colecția de tineri și repetă confirmarea YouTube.
8. Verifică faptul că alte colecții nu afișează sugestii automate.
