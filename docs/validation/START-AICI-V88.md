# Validare SongApp v88 · FreeShow vizibil

1. Pornește FreeShow și conectorul local.
2. Deschide un program SongApp care conține versuri.
3. Alege `FreeShow local` → `Trimite programul`.
4. Confirmă că prezentarea `SongApp · Titlul programului` apare și se deschide în FreeShow.
5. Confirmă că prezentarea este în categoria `SongApp`.
6. Verifică slide anterior, următor și ecran gol.

Corecția folosește `open: true` și transmite corpul REST ca `application/json`, identic cu testul PowerShell confirmat pe calculatorul bisericii.
