# Validare v101

1. Rulează `npm ci`.
2. Rulează `npm run build`.
3. Configurează cele două Redirect URLs descrise în `CITESTE-MAI-INTAI-V101.md`.
4. Verifică recuperarea prin email pe local și live.
5. Verifică resetarea administrativă cu un cont de test.

Resetarea administrativă folosește cheia privată numai pe server și cere rolul `admin` înainte de operațiune.
