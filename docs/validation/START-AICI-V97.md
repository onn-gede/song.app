2. Apasă `PowerPoint .pptx ↓`.
3. Confirmă denumirea `număr. titlu.pptx` și deschide fișierul în PowerPoint.

5. Deschide o cântare care are deja PPT/PPTX și confirmă că butonul de export nu apare.
