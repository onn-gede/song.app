# Validare SongApp v91 · bibliotecă și Project FreeShow

## Prima sincronizare

1. Actualizează FreeShow la versiunea curentă.
2. Pornește noul conector v91.
3. Deschide un program SongApp cu cel puțin două cântări.
4. Apasă `FreeShow local` → `Testează conexiunea`.
5. Apasă `Sincronizează și creează programul`.
6. Confirmă că prezentările lipsă au apărut o singură dată.
7. Confirmă că a apărut un Project FreeShow numit `SongApp · TITLU · DATA · ORA`.
8. Confirmă că Project-ul are ordinea din SongApp și slide-urile conțin numai versurile.

## A doua sincronizare

1. Trimite din nou același program.
2. Confirmă că nu apar prezentări și proiecte duplicate.
3. Confirmă mesajul cu numărul de elemente create, actualizate și reutilizate.
4. Modifică ordinea în SongApp și trimite din nou.
5. Confirmă că același Project FreeShow este reconstruit în noua ordine.

## Instrucțiuni

1. Intră în `Administrare`.
2. Confirmă că există `Instrucțiuni FreeShow`.
3. Deschide fișierul și verifică linkurile pentru FreeShow, Node.js LTS, API și conector.
