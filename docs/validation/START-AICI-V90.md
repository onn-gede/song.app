# Validare SongApp v90 · FreeShow distinct

1. Pornește FreeShow, activează API-ul REST și pornește conectorul v90.
2. Deschide un program care conține cel puțin două cântări și, opțional, un moment cu text.
3. Apasă `FreeShow local` → `Trimite programul`.
4. Confirmă că FreeShow conține câte o prezentare separată pentru fiecare cântare/moment.
5. Deschide câteva slide-uri și confirmă că afișează numai versurile, fără titlul cântării și fără `Strofa`, `Refren` sau alte etichete.
6. Confirmă că ordinea creării urmează ordinea programului.
7. Apasă `FreeShow pachet` și verifică ZIP-ul: fișierele `.show` trebuie să fie distincte și numerotate `01`, `02`, `03` etc.
8. Verifică și funcțiile cumulative v89: `F5`, `Shift + F5`, proiecție separată, control pe ecranul operatorului și închidere cu `Esc`.
