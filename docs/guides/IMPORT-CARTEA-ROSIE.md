# Import și reparare Carte Roșie — v57

Folosește instrucțiunile din [ACTUALIZARE-V57.md](ACTUALIZARE-V57.md). Comanda este `npm run import:red-book`; pentru ambele cărți, `npm run import:books`.

Versiunea v57 repară și versurile existente, cu copii private înainte de înlocuire. Catalogul conține exact 601 cântări complete. Înlocuiește citirea globală a textelor din PPT cu extragerea casetelor cu versuri din prezentarea curentă. Primul vers nu mai este eliminat doar fiindcă seamănă cu titlul.
