# SongApp v86 · 0.20.0

Această versiune adaugă testul și controlul direct al FreeShow care rulează pe același calculator cu browserul SongApp.

## Ce s-a schimbat

- configurare locală FreeShow în meniul de acțiuni al programului;
- adresă implicită `http://127.0.0.1:5506`;
- cheia API rămâne numai în browserul calculatorului respectiv;
- buton pentru testarea conexiunii;
- programul curent poate fi creat sau actualizat direct în FreeShow;
- prezentarea trimisă este selectată automat în FreeShow;
- comenzi rapide pentru slide anterior, următor și ecran gol;
- sunt acceptate numai adrese loopback (`localhost`, `127.0.0.1`, `::1`).

Actualizarea include și selectorul îmbunătățit de cântări pentru playlist din v85.

## Baza de date

Nu există script SQL nou pentru această versiune.
